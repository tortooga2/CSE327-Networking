## Installation

After Cloning the repo:

```
cd CSE-327-Repo
```

Then run:

```
npm install

npm run setup
```

Once that is completed validate your setup with:

```
npm run dev
```

### Development

-   when working on the project, make sure to create all new features in a new branch.
-   Naming policy for a branch is "feature/<feature-name>"
-   Before working make sure branch is published.
-   make sure to test your code before submitting a pull request.
    Once you are done with your feature, on git, submit a pull request to the dev branch. Not the main branch.
